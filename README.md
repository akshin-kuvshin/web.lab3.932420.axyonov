# Лабораторная работа №3 - Вёрстка макета с помощью Flexbox и Grid

## Тема работы

Дополнение макета страницы, созданной на лабораторных работах №1 и №2, с использованием Flexbox, Grid и адаптивной вёрстки.

## Вариант 2 - "Путешественник"

Навигационное меню теперь реализовано через Flexbox: ссылки выстраиваются в ряд с помощью `display: flex`, `flex-wrap: wrap` и `justify-content: center`, а на мобильных устройствах перестраиваются по 2 в ряд за счёт `flex: 1 1 50%`.

Карточки навыков собраны в Flex-контейнер с `flex-wrap: wrap`. Внутри каждой карточки используется `flex-direction: column`, что позволяет расположить заголовок, описание, список `<dl>` и прогресс-бар вертикально (сверху вниз). Количество карточек в ряду меняется адаптивно: 4 на десктопе, 2 на планшетах и 1 на мобильных устройствах.

Дашборд "Статистика прогресса" в принципе создан (раньше его не было) и реализован через Grid: 3 колонки на десктопе и планшетах через `grid-template-columns: repeat(3, minmax(0, 1fr))` и одна колонка на мобильных устройствах.

Прогресс-бары выполнены через 2 `div`-а: `class="progress-track"` с вложенным в него `class="progress-fill"`, ширина которого задаётся в процентах. Для доступности у всех прогресс-баров заданы `role="progressbar"` и ARIA-атрибуты: `aria-valuemin`, `aria-valuemax`, `aria-valuenow`.

## Нововведения в макете страницы

Макет страницы был дополнен с использованием следующих возможностей технологий Flexbox, Grid и др.:

* `display: flex` и `flex-wrap: wrap` для навигационного меню и карточек навыков;
* `flex: ...` для адаптивного количества карточек в ряду;
* `flex-direction: column` для вертикального расположения контента внутри карточек;
* `<dl>`, `<dt>`, `<dd>` для пар «Навык / Уровень» внутри карточек;
* ARIA-атрибуты и `role="progressbar"` для прогресс-баров;
* контрастные цвета прогресс-баров (оранжевый `#ffb15c` на тёмно-коричневом `#3b2416`);
* `display: grid` и `grid-template-columns: ...` для дашборда статистики;
* `<data value="...">` для числовых значений статистики;
* `gap` для отступов между Flex- и Grid-элементами;
* `@media (max-width: 900px)` и `@media (max-width: 600px)` для планшетной и мобильной вёрстки.
