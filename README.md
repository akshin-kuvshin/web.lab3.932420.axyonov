# Лабораторная работа №2 - Базовые и продвинутые возможности CSS

## Тема работы

Стилизация HTML-страницы, созданной на лабораторной работе №1, с использованием CSS.

## Вариант 2 - "Путешественник"

В соответствии с вариантом, страница посвящена теме путешествий. Для оформления использована бежево-оранжевая цветовая гамма.

В навигационной панели используется `position: sticky`, благодаря чему панель "прилипает" к верхней части страницы при прокрутке. При наведении курсора на ссылки навигации, как и было указано в ТЗ, их цвет плавно изменяется на оранжевый, а под ссылкой появляется тонкая линия.

Для заголовков всех секций явно задано `position: static`.

Также в странице продемонстрировано использование относительного и абсолютного позиционирования элементов в блоке `<aside>`.

## Структура и стилизация страницы

На странице используются следующие элементы и CSS-возможности:

* внешний файл `style.css` для основных стилей страницы;
* внутренний тег `<style>` для оформления секции "Посещённые вершины";
* встроенный атрибут `style` для задания размера шрифта кнопки отправки формы;
* `:root` с CSS-переменными для основных цветов и шрифтов;
* `font-family`, `font-size`, `font-weight` и `line-height` для оформления текста;
* `color`, `background-color`, `border` и `box-shadow` для визуального оформления элементов;
* `margin` и `padding` для управления внешними и внутренними отступами;
* `position: sticky` для навигационной панели;
* `position: static` для заголовков всех секций;
* `position: relative` для блока `<aside>`;
* `position: absolute` для позиционирования заголовка внутри блока `<aside>`;
* псевдоклассы `:hover`, `:active` и `:focus` для оформления различных состояний элементов;
* `column-count: 2` для размещения содержимого секции "Посещённые вершины" в двух колонках.

## Способы подключения CSS

В лабораторной работе продемонстрированы все три основных способа подключения CSS:

1. **Внешний CSS** — основные стили находятся в отдельном файле `style.css`, подключённом через `<link>`;
2. **Внутренний CSS** — стили секции "Посещённые вершины" находятся внутри тега `<style>` прямо в HTML-документе;
3. **Встроенный CSS** — для кнопки отправки формы используется атрибут `style` с правилом `font-size: 16px`.
